# User Guide

> Step-by-step workflow documentation will be expanded as features are implemented.

## Workflow

1. **Install** — Follow the Quick Start in README.md
2. **Download model** — `python -m posesense download-model --variant lite`
3. **Collect data** — Create labels and capture samples
4. **Train** — Train a classifier on your data
5. **Evaluate** — Review metrics and confusion matrix
6. **Activate** — Deploy the model for live use
7. **Use live** — Real-time pose recognition
